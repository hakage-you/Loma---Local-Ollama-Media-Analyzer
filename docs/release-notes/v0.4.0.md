## 主な修正

### タグ粒度 Lv2/Lv3 で解析のやり直しが多発する問題を修正

`qwen3-vl:30b` のような思考(thinking)対応モデルは、答えを出す前に大量の推論を行います。従来はコンテキスト長が 8192 固定だったため、12MP 程度の写真では画像だけで約4,000トークンを消費し、推論の途中で生成が打ち切られて**空の応答**が返っていました。これが一時的な通信エラーと誤判定され、同じ画像の解析が何度もやり直されていました。推論の長さは同じ画像でも毎回変わるため、成功したり失敗したりする挙動になっていました。

- コンテキスト長をタグ粒度に応じて自動決定するようにしました(設定で上書き可能、既定は自動)
- 不足を検知した場合はコンテキストを拡張して再試行し、拡張後の値はスキャン中は引き継ぎます
- 送信する画像を長辺 1536px まで縮小するようにしました(設定で変更可能、縦横比は保持)。解析の高速化にもつながります

### 残り時間が表示されない問題を修正

スキャンの実行中にアプリを起動すると、解析速度と残り時間が表示されないままになっていました。また、サムネイル登録の処理と AI 解析の処理をまたいで平均していたため、表示される見積りが実際より短く出ていました。

## 追加

- **詳細設定**: 設定画面を整理し、言語・モデル選択・タグ粒度以外の項目を「詳細設定」にまとめました
- **コンテキスト長 / 送信画像の最大長辺**: 解析が遅い・やり直しが多いときの調整用(通常は変更不要)
- **LLM診断ログ**: 解析1件ごとの処理内容(終了理由・トークン消費量など)を記録します。解析に失敗した場合は応答の内容も残ります
- アプリの起動・終了、スキャンのキャンセル・一時停止・再開をログに記録するようにしました
- やり直しが発生した際に、その原因となったエラー内容をログへ出力するようにしました
