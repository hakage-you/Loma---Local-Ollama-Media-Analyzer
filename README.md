# Loma (Local Ollama Media Analyzer)

Loma は、ローカル VLM (Ollama `llava`, `qwen3-vl`, `llama3.2-vision` 等の画像解析用大規模言語モデル) を用いて、PC内の画像・動画メディアを自動的に解析・自動タグ付け・カテゴリ分類・高速検索できるデスクトップアプリケーションです。

大切な写真などのプライバシー保護のため、3Dゲームが動かせる程度のスペックのPCがあればAIの学習などに利用されずに分析・分類ができるように作りました。<br>
(非サポートですが、API keyを設定することでクラウドのVLMを利用した解析も可能です。)

※設計、仕様検討、レビュー、動作確認だけは頑張ってますが、コードを書く部分についてはすべて生成AIに作ってもらってます。

## 1. 概要

- **🤖 ローカル VLM 自動タグ付け**:
  - ローカルで動作する Ollama VLM と連携し、完全オフライン環境で安全にメディアを解析します。
  - 画像（PNG, JPG, WebP, BMP）および動画（FFmpeg連携によるフレーム抽出）を自動解析。
  - 分類結果に基づいて、事前に用意してあるカテゴリ分類と、画像ごとに複数のタグを自動で付与を実行します。
  - モデル規模（10Bパラメータ基準）に応じた最適プロンプト（`DETAILED`(高精度) / `LIGHT`(省メモリ)）の動的切替を行うため、VRAMの少ないGPUでも動作する想定です。高精度の方が適切かつ多くのタグ付けができるので楽しいと思います。

- **🎛️ フィルタ機能**:
  - カテゴリやファイルの種類ごとに表示をフィルタリングすることで特定の条件に合致するメディアを抽出できます。

- **🔍 タグ検索機能**:
  - 同じタグが付与されたメディアを検索、一覧することで意外な繋がりをもつ写真たちを発見することができるはずです。

- **🔗 タグマージ機能**:
  - VLMにより自動で付与されるタグには微々たるゆらぎがあるため、似た意味を持つタグが複数登録されてしまうことがあります。タグマージ機能により、意味の似通ったタグを自動検出し、マージを行うことでタグによる検索性を向上させることができます。
  - AIの解析によって類似したタグを自動で検出し、統合を提案します。これも意思を持って特別の設定をしないかぎりクラウドにデータが送信されることはありません。

## 2. 動作環境のセットアップ

### 2.1. ollamaのインストールとセットアップ

1. 公式サイトからollamaをダウンロードしてインストールする

   Ollamaで検索して！リンク切れ対応とか面倒なのでリンクは貼りません。ごめんね！

2. Ollama にVLMを追加する

   `qwen3-vl` `gemma4` などの vision対応モデルをOllamaに追加する。 コマンド例: `ollama run qwen3-vl` 
   
   **ここに書かれている意味がわからない場合はオススメLVMをインストールする機能があるためこの手順は無視してください。**

### 2.2. (Option) FFmpegのインストールとセットアップ

※動画の解析をしたい人だけやってください。

1. 公式サイトからFFmpegをダウンロードしてインストールする

   これもリンク切れ対応とか面倒なので検索して！ほんまごめん。

## 3. 使用方法

### 2.1. モデルの設定

1. **モデルのダウンロードまたは設定**:
   
   1.1 設定(歯車マークボタン)画面で使用するモデルを選択する



### 2.2. フォルダの追加とスキャン

1. **監視フォルダの追加 (`[Add Folder]`)**:
   - ヘッダーの `[Add Folder]` ボタンを押して、画像や動画が保存されているフォルダを選択します。
   - フォルダ内のメディアが自動スキャンされ、サムネイルが先行生成された後に VLM による解析キューが開始されます。

2. **フォルダ同期 (`[Sync]`)**:
   - ヘッダーの `[Sync]` ボタンを押すと、登録済みの全フォルダ内の差分をスキャンします。
   - 新規追加ファイル、削除ファイル、および**移動・リネームされたファイル**が自動検知され、移動されたメディアは再解析なしでパスが更新されます。

3. **メディアの閲覧・絞り込み**:
   - **サイドバー**: 固定カテゴリ（12種）、メディア種別（画像 / 動画）、ステータス（Pending / Completed / Failed）でフィルタリング。
   - **検索バー**: タグ名（英語または日本語）を入力して直接検索。
   - **詳細検索モーダル**: 検索バーサジェスト右上の `[詳細検索]` をクリックすると、GUI で `AND`/`OR`/`NOT` 条件を組み立てて検索できます。

4. **設定 (`⚙️ Settings`)**:
   - ヘッダーの歯車アイコンから設定モーダルを開きます。
   - **UI Language**: 表示言語（日本語 / English）の変更。
   - **FFmpeg通知**: FFmpeg未インストール時のアナウンス通知の ON/OFF 切替。
   - **Ollama 設定**: Endpoint URL の変更、Vision モデル選択、VRAM アンロード。

## 3. ビルドおよび開発手順

### 3.1 前提条件

アプリのビルドおよび動作には以下のツールが必要です。

1. **[Node.js](https://nodejs.org/)**: v18 以上推奨
2. **[Rust](https://www.rust-lang.org/)**: Cargo 1.75 以上推奨
3. **[Ollama](https://ollama.com/)**:
   - ローカル環境で Ollama サービスが起動していること (`http://localhost:11434`)。
   - Vision 対応モデル（例: `qwen3-vl`, `llava`）がダウンロードされていること。
4. **FFmpeg** *(任意)*:
   - 動画ファイル（`.mp4`, `.mkv`, `.mov` 等）のフレーム抽出・解析を行う場合は必要です。未インストールの場合は動画処理が自動的にスキップされます。

### 3.2 ビルド・利用方法

#### 1. 依存関係のインストール

```bash
npm install
```

#### 2. 開発サーバーの起動 (Dev Mode)

```bash
npm run tauri dev
```

#### 3. プロダクションビルド (Executable & Installer)

```bash
npm run tauri build
```
ビルド完了後、実行ファイルおよびインストーラが `src-tauri/target/release/bundle/` 配下に生成されます。

#### 4. テストおよび動作チェック

```bash
# フロントエンド TypeScript チェック
npm run build

# バックエンド Rust チェック
cd src-tauri
cargo check
cargo test
```
